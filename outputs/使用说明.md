# 深圳大学校园网保活

双击 **启动校园网保活.vbs** 打开窗口，无需安装 Selenium 或 ChromeDriver。
首次打开会做一次只读状态检查，**不会自动开启定时保活**。点击“开始保活”后，立即检查并在需要时登录。

## 窗口怎么用

- **登录状态**：只有认证接口返回当前账号的有效在线记录才显示“已成功登录 / 在线”。绿色状态代表最近一次检查结果，并非持续实时监测。
- **开机启动**：窗口从当前 Windows 用户的启动项读取状态；勾选方框开启，取消勾选关闭。这里的“开机”指登录 Windows 后，不是登录前。
- **本次启动**：区分“手动启动”和通过本程序启动项进行的“开机自动启动”。
- **保活间隔**：单位是分钟，默认 15，可设置 0.5～1440。修改后点“保存设置”；运行中保存会唤醒一次检查，再使用新间隔。
- **认证区域**：默认“自动兼容两区”；需要排查时可临时选“仅教学区”或“仅宿舍区”。
- **立即检查 / 登录**：单次检查，必要时登录；运行保活时会提前唤醒检查，不会另开重复登录线程。
- **停止保活**：取消后续检查，等待当前网络请求结束。不会注销校园网或终止其他 Python 程序。
- **最小化 / 点右上角 ×**：最小化继续运行；× 把窗口隐藏到右下角托盘，**不会停止已经开启的保活**。隐藏不会自动开启尚未开始的保活。
- **恢复窗口**：点击托盘里的蓝色 **N** 图标，或右键图标选择“显示窗口”；也可以再次双击 VBS，恢复同一窗口，不会启动第二份。图标可能藏在托盘的向上箭头 / 隐藏图标区域。
- **真正退出**：右键托盘 →“退出程序（停止保活）”，或窗口左上角“程序”→“退出程序（停止保活）”。这会停止保活、移除托盘图标，但不会注销校园网。若已启用开机启动，下次登录 Windows 仍会启动；彻底停用请先取消勾选。

鼠标停在托盘图标上可看到当前运行状态和最近检查的登录状态。若 Windows 暂时无法创建托盘图标，程序不会隐藏到无法找回的位置，而会保持窗口可见；资源管理器重启后会尝试恢复图标。

开机启动开启后，登录 Windows 会自动打开窗口并开始保活，不需要再次点击按钮。不要移动本文件夹；移动后请在新位置重新勾选开机启动。若被 Windows 安全策略或任务管理器禁用，也需要在那里允许本程序启动。

## 登录判断与网页反馈

程序使用两个学校页面实际调用的接口，不需要等待浏览器跳转，也不使用 Google 连通性检查网址：

- 宿舍区：从 `http://172.30.255.42/a79.htm` 读取当前连接参数；通过 `/drcom/chkstatus` 检查在线状态，按页面配置选择认证方式。
- 教学区：从 `https://net.szu.edu.cn/` 跟随学校本次给出的入口，读取当前 IP 和接入编号，通过 `/cgi-bin/rad_user_info` 检查在线状态。

旧网址中的客户端 IP、MAC、接入编号与“登录成功页”路径不会被硬编码为登录依据。自动模式先检查两套系统是否已经在线；未在线才尝试可用入口。提交后还会重新查在线记录，单有“登录成功”字样不能算成功。

“认证响应（脱敏）”标签显示本程序请求的接口地址、时间、返回状态和在线数据；这是抓取网页使用的认证接口响应，不是监听其他应用的流量。密码、认证令牌、加密登录报文及 Cookie 不写入日志。最近一次反馈保存在 `data/last_response.json`，运行日志在 `data/keepalive.log`（自动限制大小）。分享前仍应检查其中的账号和 IP。

## 密码与运行条件

密码在输入框中隐藏，保存时使用 Windows DPAPI 按当前用户加密，配置文件不会明文保存密码。复制到另一台电脑或换 Windows 账号后需要重新输入。它不能防止同一 Windows 用户下的恶意程序读取正在使用的密码。

宿舍区接口本身使用 HTTP，传输安全程度与学校原网页相同；程序不会将密码提交给两个指定认证站点以外的域名。

已在线时只做状态检查，不反复登录、不强制踢下线。普通连接失败会按 30、60、120、240、300 秒逐步重试（不超过设定的正常间隔）；明确的密码/验证码错误或其他账号在线时会暂停，避免反复尝试。此时检查提示、修正设置，然后重新点击“开始保活”。

电脑关机、睡眠、Wi-Fi 断开、校园网故障、账号过期等情况下不能保证不断网。保活是定时检查和重登，短于设置间隔的断网可能要等下一次检查才会处理。在线记录也不等同于每个外部网站都能访问。

## 测试和排错

1. 双击 VBS，确认可看到窗口、当前系统时间和“开机启动：未开启/已开启”。
2. 点击“立即检查 / 登录”，查看日志和认证响应。已在线应提示“无需重复登录”。
3. 记下原间隔，临时改为 **0.5**，保存并开始；点 × 隐藏，等约 30 秒后从托盘恢复，确认日志出现新一轮检查，然后改回原间隔并保存。
4. 点击“停止保活”，确认显示已停止、下次检查变为横线。需要彻底关闭时，使用托盘或“程序”菜单里的“退出程序”。
5. 可勾选开机启动，然后下次正常登录 Windows 时确认“本次启动：开机自动启动”。无需为了测试现在重启或退出校园网。

如果双击无反应，用 **排错启动.bat**，它会保留错误信息。重复双击会恢复已经运行的窗口，不会运行第二份保活。

开发检查（PowerShell；先进入当前文件夹）：

```powershell
python .\campus_keepalive.py --status  # 只读检查，不提交密码
python .\campus_keepalive.py --once    # 单次检查，必要时登录
python .\campus_keepalive.py --smoke-gui  # 无联网的界面自检
python .\campus_keepalive.py --start  # 手动打开并立即开始保活；不修改开机启动项
python -m unittest discover -s ..\tests -v
```

源代码分为 `campus_keepalive.py`（窗口）、`campus_tray.py`（Windows 托盘）与 `campus_core.py`（认证、加密保存、开机启动与调度）。`data` 是运行数据文件夹，三个 Python 文件需放在一起。托盘只用 Python 标准库，不需要额外安装依赖。
