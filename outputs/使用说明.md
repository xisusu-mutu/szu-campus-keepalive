# 深圳大学校园网保活

双击 **启动校园网保活.vbs** 打开窗口。普通启动先检查一次状态；填写账号、密码并保存后，点击“开始保活”。

## 窗口操作

- **登录状态**：显示认证接口查询到的在线状态。
- **开机自动保活**：点击加大的方框或文字切换，直接显示“已开启 / 已关闭”；也可用 Tab 聚焦后按空格切换。开启后在登录 Windows 时自动打开程序并开始保活。
- **本次启动**：显示手动启动或开机自动启动。
- **保活间隔**：单位为分钟，默认 15，范围 0.5～1440。修改后点击“保存设置”。
- **认证区域**：自动兼容两区，也可选择仅教学区或仅宿舍区。
- **立即检查 / 登录**：立即检查当前状态，必要时登录。
- **停止保活**：停止定时检查。
- **右上角 ×**：隐藏到右下角托盘。
- **恢复窗口**：点击托盘中的蓝色 **N** 图标，或再次双击启动文件。
- **退出程序**：右键托盘，或在窗口“程序”菜单中选择“退出程序（停止保活）”。

托盘图标可能位于向上箭头展开的隐藏区域。移动项目后，请在新位置重新设置开机启动。

## 登录状态与日志

程序根据学校认证入口获取当前连接参数：

- 宿舍区：从 `http://172.30.255.42/a79.htm` 获取接入参数，通过 `/drcom/chkstatus` 查询在线状态。
- 教学区：从 `https://net.szu.edu.cn/` 获取入口和接入编号，通过 `/cgi-bin/rad_user_info` 查询在线状态。

自动模式先查询两区在线状态，再对可用入口发起登录并重新核验。账号或密码错误导致暂停时，修正设置后点击“开始保活”。

其他账号在线时，保活保持运行，按设置的保活间隔继续查询；不注销或替换该账号。确认没有账号在线后，再使用已保存的账号密码登录。

运行日志位于 `data/keepalive.log`，配置位于 `data/settings.json`。

密码使用 Windows 当前用户的 DPAPI 保存。更换电脑或 Windows 账号后，重新输入账号密码。

## 测试与排错

1. 启动窗口，确认系统时间、登录状态和开机启动状态正常显示。
2. 点击“立即检查 / 登录”，查看登录状态和运行日志。
3. 将间隔临时改为 **0.5**，保存并开始保活，约 30 秒后查看新一轮日志；测试后改回原间隔。
4. 点击“停止保活”，确认状态变为已停止。
5. 测试自启时，勾选开机启动，并在下次登录 Windows 后查看启动状态。

双击无反应时，运行 **排错启动.bat** 查看错误信息。

在当前文件夹打开 PowerShell：

```powershell
python .\campus_keepalive.py --status     # 查询认证状态
python .\campus_keepalive.py --once       # 单次检查 / 登录
python .\campus_keepalive.py --smoke-gui  # 界面自检
python .\campus_keepalive.py --start      # 打开并开始保活
python -m unittest discover -s ..\tests -v
```

源代码包括 `campus_keepalive.py`（界面）、`campus_tray.py`（托盘）和 `campus_core.py`（认证、配置、自启与调度），三个文件放在同一目录。运行环境使用带有 `tkinter` 的 Python 标准库。
